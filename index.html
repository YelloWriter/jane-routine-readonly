도구 소개개인정보 안내이용약관

Jane Routine Readonly

운영자 개인의 Google 메일·일정을 읽기 전용으로 연결하기 위한 안내입니다.

어떤 도구인가요?

운영자가 허용한 본인 계정의 메일과 일정을 확인해 개인 업무 요약을 준비하는 도구입니다. 일반 사용자의 회원가입이나 계정 연결 신청은 받지 않습니다.

Google 계정 연결과 동의는 Google의 공식 인증 화면에서 진행합니다. 이 안내 사이트에서 로그인 정보나 인증 코드를 입력받지 않습니다.

접근 범위

  • Google 메일 읽기 권한과 Google Calendar 읽기 권한만 사용합니다.
  • 실제 조회는 운영자가 별도로 허용한 계정·기간·최소 항목으로 제한합니다.
  • 메일 발송·수정·삭제, 일정 생성·수정·삭제 권한은 요청하지 않습니다.
  • 메일 본문·첨부파일이나 일정 설명 등은 기본 조회 대상에 포함하지 않습니다.

연결과 정기 실행은 별개입니다

계정 연결만으로 자동 수집·게시·발송이 시작되지 않습니다. 정기 실행과 외부 전달에는 운영자의 별도 승인이 필요합니다.

이 도구는 진단·처방·의료기관 전송 서비스가 아니며, 다른 제품의 계정 연결 도구를 대신하지 않습니다.
