1. 대상과 목적

이 도구는 운영자 본인의 승인된 Google 계정만 연결해 개인 업무 확인과 요약 준비에 사용합니다. 공개 사용자 등록이나 일반 방문자의 Google 데이터 수집 기능을 제공하지 않습니다.

2. 접근하는 Google 데이터

Gmail 및 Google Calendar의 읽기 권한을 사용하되 실제 처리는 별도로 승인된 계정·기간·항목으로 제한합니다. 기본 항목은 메일 제목·발신자 표시·수신 시각과 일정 제목·시작 및 종료 시각입니다. 이메일 본문·첨부파일·일정 설명·위치정보를 기본 수집하지 않습니다.

메일 발송·라벨 수정·삭제, 일정 생성·수정·삭제는 하지 않습니다. 이 도구의 연결을 Drive·연락처 등의 추가 서비스 접근 승인으로 확대하지 않습니다.

3. 처리·보관과 공유

연결 자격증명은 운영자의 기기 내 전용 보관 위치에서 취급하며, 이 안내 사이트나 공개 저장소에 올리지 않습니다. 실제 조회 결과는 허용된 로컬 요약에 필요한 범위에서만 처리합니다. 기본 원시 메일·일정 응답을 공개 문서에 보관하지 않습니다.

별도 승인 없이 외부 게시·발송·제3자 전달을 하지 않습니다. Google 사용자 데이터를 판매하거나 광고 타기팅에 사용하지 않습니다. Google API로 받은 정보의 사용·전달에는 Google API Services User Data Policy와 해당되는 Limited Use 요구사항을 따릅니다.

데이터를 외부 AI나 다른 처리 서비스로 전달할 필요가 생기면 대상·목적·범위를 먼저 별도로 확인하며, 이 안내를 그러한 전달의 포괄 동의로 사용하지 않습니다.

4. 보관 종료와 연결 해제

연결 해제는 Google 계정의 서드 파티 앱 및 서비스 연결 관리에서 직접 할 수 있습니다. 로컬 보관 자료의 삭제·변경은 운영자가 지정한 범위와 방법으로만 진행합니다. 연결 해제가 이미 생성된 로컬 요약의 자동 삭제를 뜻하지는 않습니다.

5. 안내 사이트 방문 정보

안내 페이지에는 로그인·입력 양식·분석용 스크립트·광고를 넣지 않습니다. 다만 GitHub Pages 호스팅 제공자는 사이트 방문자의 IP 주소 등 보안·운영 기록을 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 확인해 주세요. 이 안내 사이트는 Google 메일·일정 데이터를 호스팅 서버로 전송하는 기능이 없습니다.

6. 문의와 변경

개인용 도구의 운영·연결·보관 정책은 운영자가 관리합니다. 공개 연락 경로는 운영자 GitHub 프로필입니다. 공개 게시물에 메일·일정·인증정보를 남기지 마세요. 처리 방식이 바뀌면 이 안내를 먼저 갱신하고 필요한 별도 동의를 확인합니다.
